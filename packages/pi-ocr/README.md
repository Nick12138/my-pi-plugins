# OCR (Baidu) — pi 插件

把百度智能云 OCR 封装成 pi 的三个工具（移植自 `baidu_ocr` Claude 技能）：
- `ocr_image`：单张通用识别（可切高精度档）
- `ocr_images`：批量识别（并发控制 + 逐张失败隔离）
- `ocr_certificate`：证照专用结构化识别（营业执照 / 身份证 / 驾驶证 / 行驶证 / 发票）

## 功能

- 通用文字识别·标准版 `general_basic`；**可选高精度档 `accurate_basic`**（`accuracy: "accurate"`，识别更准，专治盖章压字/扫描发虚，两档免费额度相同）
- 始终带上 `detect_direction=true`、`paragraph=true`、`probability=true`：横拍/倒置图片也能识别，且能查看方向与平均置信度
- **证照专用接口**：`ocr_certificate` 走百度专用端点，返回**结构化字段**（而非自由文本）：
  - `business_license` 营业执照（信用代码/企业名称/法人/注册资本/经营范围…）
  - `idcard` 身份证（正反面分传：`side: "front"/"back"`）
  - `driving_license` 驾驶证、`vehicle_license` 行驶证（车辆识别代号/发动机号等）
  - `vat_invoice` 增值税发票（发票号/金额/税额/商品明细…）
  - 字段名已中文化，未收录的字段原样显示 key
- **批量识别**：`ocr_images` 一次传多张图，内置并发池（默认 2，可设 1–10），单张失败不影响其余图片
- **可选落盘**：传 `outputPath` 就把结果以 txt 形式追加写入本地文件（不传则只回传上下文）
- Access token 内存缓存 + 并发去重：一次批量只会发 1 次 token 请求；token 失效（100/110/111）会自动重取重试一次
- **错误码友好提示**：17/18/19（额度/QPS）、216630（图片模糊）等映射成可执行建议
- 图片限制：base64 ≤ 4MB、最长边 ≤ 4096px，超限给出压缩建议

## 配额与 QPS（重要，参考官方 2025 口径）

| 项目 | 未付费 | 开通按量后付费 |
| --- | --- | --- |
| 免费测试资源 | 通用标准版/高精度版均为**个人认证 1000 次/月、企业认证 2000 次/月**（证照接口各有独立免费额度，以控制台为准） | 按量计费（量越大单价越低） |
| QPS | **2** | **10**（仍不够可买 QPS 叠加包，10 元/天/QPS） |

- 官方**没有本地文件的批量接口**（FAQ 明确"暂不支持批量识别"），推荐做法就是 **QPS 允许范围内的多线程调用**——`ocr_images` 的并发实现正是这个方案
- 所以未付费账号默认并发 **2**（超了会报 `error 18`）；付费后可把 `concurrency` 调到 10
- 实际配额以你控制台里应用显示的为准：https://console.bce.baidu.com/ai/ → 文字识别 → 应用列表

## 工具

### ocr_image — 单张通用识别

```
ocr_image(imagePath: string, accuracy?: "standard"|"accurate", outputPath?: string)
```

返回：识别文本（逐行）＋ 方向 / 行数 / 平均置信度元信息。

### ocr_images — 批量识别

```
ocr_images(imagePaths: string[], accuracy?: "standard"|"accurate", outputPath?: string, concurrency?: number)
```

- `imagePaths`：图片路径列表，一张图 = 一次 API 调用（计入你的配额）
- `accuracy`：整批统一档位，默认 `"standard"`；扫描件模糊可选 `"accurate"`
- `concurrency`：并发数，1–10，默认 2（未付费 2 QPS；付费后可 10）
- 返回：汇总（共 X 张 / 成功 / 失败 / 并发数 / 档位）＋ 逐张结果块；单张失败单独标明，不影响其他图片

### ocr_certificate — 证照专用结构化识别

```
ocr_certificate(imagePath: string, type: "business_license"|"idcard"|"driving_license"|"vehicle_license"|"vat_invoice", side?: "front"|"back", outputPath?: string)
```

- `type` 对照：营业执照 / 身份证 / 驾驶证 / 行驶证 / 增值税发票
- `side`：仅 `type="idcard"` 生效，`front`=正面（人像+姓名）、`back`=反面（签发机关+有效期），默认 front
- 返回：字段名 + 值的结构化列表（已中文化）；发票额外附商品明细
- 专用接口推断字段——**关键字段（信用代码/证件号/金额）务必与原图交叉核对**

## 输出与落盘规则

- **识别结果始终回传上下文**（工具返回值），同时带 `source/行数/方向` 等元信息
- 传了 `outputPath` 时：
  - **追加写入**（不会覆盖已有内容），每次请求一条记录，记录 = 绝对图片路径 + 识别信息
  - 单张：每调用追加一条记录；批量：只写 **一个文件**，按 **请求** 落一条记录（不做成每张一个文件）
  - 证照：落一条"证照识别 · 营业执照（business_license）"记录（路径 + 中文字段）
  - 父目录不存在会自动创建；新建文件带 UTF-8 BOM，记事本/WPS 打开不乱码
  - 批量且设了 `outputPath` 时，上下文里的逐张文本截断到 1200 字符（完整文本在磁盘文件里）
  - 落盘失败不会让识别失败：上下文会标注"落盘失败: xxx"，识别结果照常返回

## 常见错误码速查

| 错误码 | 含义 | 处理 |
| --- | --- | --- |
| 17 | 当日可用额度用尽 | 控制台核对配额，或开通按量后付费 |
| 18 | QPS 超限 | 未付费账号 QPS=2：把并发降到 2；付费后升 10 QPS |
| 19 | 请求总量超限 | 控制台核对配额 |
| 100/110/111 | access_token 无效/过期 | 插件已自动重取重试；仍失败检查 API Key / Secret Key |
| 216630/216631 | 图片模糊/过暗 | 换更清晰的图，或改 `accuracy: "accurate"` |
| 216202 | 图片过大 | base64 ≤ 4MB、最长边 ≤ 4096px |

## 配置（环境变量，PiDeck 配置界面自动注入）

| 环境变量 | 说明 | 必填 |
| --- | --- | --- |
| `BAIDU_OCR_API_KEY` | 百度 OCR 应用 API Key | ✓ |
| `BAIDU_OCR_SECRET_KEY` | 百度 OCR 应用 Secret Key | ✓ |

密钥只存在于进程环境变量，插件代码不打印、不回传、不落盘。

## 申请密钥

1. 登录 https://cloud.baidu.com/
2. 打开 https://console.bce.baidu.com/ai/ → 文字识别 → 应用列表 → 创建应用
3. 勾选需要的接口（通用文字识别标准版/高精度版 + 用到的证照接口），创建后复制 **API Key** 和 **Secret Key** 填入插件配置

## 与原技能的差异

- 密钥不再内嵌在说明文件里，只走环境变量
- 交互模式 / `--output` JSON 落盘改为 pi 工具返回值，不产生需要手动清理的临时文件
- 证照识别做成真实调用（`ocr_certificate`，结构化字段输出），而非仅仅文字提示
- 新增批量能力（并发解析、失败隔离）与可选 txt 落盘（按请求追加、单文件记录）
- 错误码映射为可操作提示；token 失效自动重取；并发默认值按未付费 2 QPS 配置
